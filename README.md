# Snake RL
This project explores the development of an AI agent capable of playing the classic Snake game using both reinforcement learning (RL) and classical heuristic search techniques. We focused on designing and evaluating a custom Snake environment to support the training and benchmarking of these agents. For the RL approach, we implemented and trained agents using Proximal Policy Optimisation (PPO), with an emphasis on optimising the reward structure using traditional methods as well as Large Language Models (LLMs). In parallel, we designed heuristic strategies to provide a baseline for comparison. The project highlights the trade-offs between RL and traditional methods in terms of adaptability, efficiency, and complexity.
